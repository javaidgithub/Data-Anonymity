File Anonymization System is a web-based tool that automatically detects and anonymizes Personally Identifiable Information (PII) in uploaded CSV, PDF, and DOCX files. Built using FastAPI for the backend and HTML/CSS/JavaScript for the frontend, this system uses regular expressions and the Faker library to replace sensitive data like emails, phone numbers, IP addresses, and SSNs with realistic fake values. It provides a secure and user-friendly way to share documents without risking data privacy. Ideal for researchers, analysts, and organizations handling sensitive information.
